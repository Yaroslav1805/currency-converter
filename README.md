# Конвертер валют

Веб-приложение для конвертации валют с актуальными курсами.

## Функции
- Конвертация между 5 валютами (USD, EUR, RUB, BYN, KZT)
- Актуальные курсы с API
- История конвертаций
- Светлая/темная тема
- Адаптивный дизайн

## Технологии
- HTML5, CSS3, JavaScript
- ExchangeRate API
- LocalStorage
